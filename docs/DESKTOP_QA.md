# 桌面版验收清单

这份清单针对的是**只能人工验收**的部分：需要可见窗口、真实麦克风或系统权限的行为。
自动化测试（`npm test`）覆盖不到这些，所以没跑过就不能说它работает。

## 为什么必须在打包产物上验收，而不是 `tauri dev`

`tauri dev` 跑的是裸二进制，**不是带 usage description 的签名 bundle**。实践中表现为
麦克风在 dev 下静默失败、而在 `.app` 里正常。所以：

```bash
npm run build:debug     # → apps/desktop/src-tauri/target/debug/bundle/macos/Step酱.app
open apps/desktop/src-tauri/target/debug/bundle/macos/Step酱.app
```

从构建产物目录直接打开**不会触发 Gatekeeper** —— quarantine 属性只在下载/AirDrop 时附加。
只有分发 DMG 才需要走「系统设置 → 隐私与安全性 → 仍要打开」。

## 权限会反复弹的原因（别以为是 bug）

TCC 授权是**绑定代码签名身份**的。本地 ad-hoc 签名在很多次重建后身份会变，
于是麦克风和录屏授权重新弹窗，旧的授权记录也不再适用。

**演示前的正确做法：构建最后一版 → 在那个二进制上授权 → 之后不要再重编。**

需要重置授权时：

```bash
tccutil reset Microphone com.stepfun.stepchan.pet
tccutil reset ScreenCapture com.stepfun.stepchan.pet
```

## 清单

### 窗口形态
- [ ] 角色显示为**无背景**：没有白底、没有窗口边框、没有矩形阴影光晕
      （阴影光晕说明 `shadow(false)` 没生效）
- [ ] 常驻在其他窗口之上
- [ ] **切到全屏应用（如全屏 Safari）后仍然可见** —— 这一条专门验 Tauri 自带的
      `always_on_top` 不够、需要手动设 `FullScreenAuxiliary` + `NSStatusWindowLevel`
- [ ] 切换 Space（多桌面）后仍然可见
- [ ] Dock 里**没有**图标，菜单栏里**有**图标

### 点击穿透（最容易出错的一块）
- [ ] 点角色身上有反应
- [ ] 点角色旁边的透明区域，点击**穿透到下层应用**（例如穿透到下面的 Finder 窗口并选中文件）
- [ ] 鼠标**快速划过**角色边缘，不出现「该响应却没响应」或「该穿透却被吃掉」
      （这验的是滞回外扩是否生效；切换是异步派发到主队列的，有一帧延迟）
- [ ] 拖动角色可以移动位置，松手后回到穿透判定
- [ ] 外接显示器 / Retina + 1x 混合 DPI 下命中位置正确
      （Tauri 的 `cursor_position()` 在混合 DPI 下换算有已知 bug，所以实现用的是 `NSScreen` frames）

### 麦克风与语音
- [ ] 首次开启语音时弹出麦克风授权，**只弹一次**（弹两次说明 `on_permission_request` 没挂上）
- [ ] 授权后能听到她说话
- [ ] **说话打断**：她说到一半时开口，她立刻停（不是说完才停）
- [ ] 界面上能看到自己说的话的实时字幕
- [ ] 控制台里确认 `AudioContext.sampleRate` 实际值与发送给 realtime 的采样率一致
      （WKWebView 可能不按 `{sampleRate: 24000}` 给，会静默 clamp 到设备采样率）
- [ ] 换音色后仍能正常对话（换音色会重建会话 —— 模型首次出音后 voice 不可改）
- [ ] 连续对话超过 30 分钟不断线（会话上限 30 分钟，到期要静默重建）

### 第四面墙
- [ ] 屏幕感知**默认关闭**；关闭时让她看屏幕，她会说"要先打开开关"而不是瞎编
- [ ] 开启后首次使用弹出录屏授权；拒绝时有明确可操作的提示，不崩
- [ ] 授权后她能说出屏幕上大致在干什么
- [ ] **每次看屏幕都有可见提示**（不能静默截屏）
- [ ] 拖一个文件到她身上，她有反应
- [ ] 前台应用感知默认关闭；开启后切换应用她偶尔搭话，且**不会刷屏**（有防抖和配额）
- [ ] `set_timer` 到点真的弹出 macOS 系统通知

### 托盘菜单
- [ ] 各项勾选状态与实际行为一致，重启后保留
- [ ] ⌥Space 能唤起对话
- [ ] 退出能真正退出（不留后台进程）

### 降级与异常
- [ ] 没有 `.env` / key 为空时，有明确提示而不是白屏
- [ ] 断网时有明确提示，恢复后能自动重连
- [ ] 素材加载失败时退回基础立绘并提示，不白屏
